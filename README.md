# student-management
Student Management System

A simple Student Management System made using Python as part of my learning journey in computer applications.

I created this project to practise Python programming and understand how basic concepts can be used to build something practical. It runs in the terminal and allows users to manage student records through a simple menu.

Features

* Add Student: Add a new student with their details.
* View Students: Display the list of registered students.
* Search Student: Find a student using their roll number.
* Remove Student: Delete a student record using their roll number.
* Input Validation: Handle invalid inputs and prevent duplicate roll numbers.
* Menu-Driven Interface: Choose different operations through a simple terminal menu.

Technologies Used

* Python 3
* Lists and dictionaries
* Loops and conditional statements
* User input and input validation

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python Std-mgmt.py

Make sure the filename matches the Python file in your repository.

Things to Know

Currently, student records are stored in memory, so they are available only while the program is running. Once the program closes, the records are lost.
